## Overview
NikOmicsDogma is a Python-based interactive framework for exploring 
multiomics relationships and central dogma concepts through systems 
biology visualization and biological knowledge integration.

---

## Planned Features
- DNA → RNA → Protein interactive visualization
- Multiomics data integration and exploration
- Biological network analysis
- Systems biology visualization modules
